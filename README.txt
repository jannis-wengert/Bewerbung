
BEWERBUNGS-VORLAGE – TYPST
===========================

Dateien
-------
theme.typ        Gemeinsames Layout für Lebenslauf und Anschreiben
data.typ         Persönliche Daten + Firmendaten
lebenslauf.typ   Lebenslauf
anschreiben.typ  Anschreiben

Vorgehen
--------
1. Ordner in VS Code öffnen.
2. Tinymist/Typst-Erweiterung verwenden.
3. In data.typ pro Bewerbung nur Firmendaten und Betreff ändern.
4. Anschreiben in anschreiben.typ inhaltlich auf die jeweilige Firma anpassen.
5. lebenslauf.typ grundsätzlich unverändert lassen; nur relevante Stichpunkte
   bei Bedarf leicht anpassen.
6. Optional foto.jpg in den Ordner legen und die image-Zeile in lebenslauf.typ
   aktivieren.

Designidee
----------
- A4, viel Weißraum
- dunkelblauer Akzent
- keine Skill-Balken oder Prozentwerte
- klare Datums-/Inhaltsspalte
- Lebenslauf und Anschreiben nutzen exakt dieselbe Typografie

Wichtig
-------
Die Stichpunkte zu AGCO/Fendt, ZEISS und Vetter sind bewusst noch allgemein.
Sie sollten anhand der tatsächlichen Tätigkeiten/Zeugnisse konkretisiert werden.
